Colour by Numbers

Plate viewer

Review a generated colour plate on any device (including iPad): upload an image, clamp it to the colouring palette, and preview the numbered outline. Generation runs in Streamlit/CLI via fal.ai — this page does not call image APIs or need keys.

Generate sets locally with streamlit run testbed_app.py or colour-by-numbers --illustrate --set-size N using FAL_KEY, then upload plates here to inspect outlines on a tablet.
